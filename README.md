## ✨ Features

| Feature | Description |
|---------|-------------|
| 🎨 **Glassmorphism UI** | Frosted glass panels with backdrop blur and smooth hover effects. |
| 🌓 **Dark / Light Mode** | User-preference toggle saved in `localStorage`. |
| ⌨️ **Typing Animation** | Dynamic text rotator ("web", "future", "users", "world") with blinking cursor. |
| 🔍 **Scroll Reveal** | Elements fade/slide into view when they enter the viewport. |
| 📱 **Fully Responsive** | Mobile-first design with hamburger menu and fluid grids. |
| 🧩 **Projects Showcase** | Three featured project cards – each with tech stack, description, and icon links. |
| 📬 **Contact Form** | Simulated submission (loading + success state) – no backend required. |
| ⚡ **Smooth Navigation** | Active link highlighting, fixed header, and anchor scrolling. |

---

## 🛠️ Technologies Used

- **Markup & Styling:** HTML5, CSS3 (Flexbox, Grid, CSS Variables, Keyframes)
- **Interactivity:** Vanilla JavaScript (ES6+)
- **Icons:** Font Awesome 6 (free CDN)
- **Typography:** Google Fonts – Outfit (sans-serif) + Fira Code (monospace)
- **Animations:** CSS transitions, Intersection Observer API, custom typing effect
